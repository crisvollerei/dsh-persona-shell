## 安装

需要已支持插件管理的 **DSH Desktop 或 Web**。开发与验证基于 `0.2.2-rc.1`，兼容 `0.2.1-rc.3` 及以上、`0.3.0` 之前的版本；其他版本的兼容性请以实际使用为准。

### 推荐：从 npm 安装

```bash
dsh plugin --profile <profile> add dsh-persona-shell
```

也可以在侧边栏 **Plugins → Add plugin** 中选择 **Install a third-party plugin**，填入包名 `dsh-persona-shell`。

安装后启用该 bundle；如果 DSH 提示重启，重启一次客户端。随后打开 **设置 → 人格套壳**，选择预设即可。

### GitHub Release（Tarball）

从 [Releases](https://github.com/crisvollerei/dsh-persona-shell/releases) 下载当前版本的 `dsh-persona-shell-<version>.tgz`，然后在 **Plugins → Add plugin** 中选择 **Install a third-party plugin**，填入下载链接，例如：

```text
https://github.com/crisvollerei/dsh-persona-shell/releases/download/v0.5.1/dsh-persona-shell-0.5.1.tgz
```

也可以下载后通过 CLI 安装本地 tarball：

```bash
dsh plugin --profile <profile> add ./dsh-persona-shell-0.5.1.tgz
```

### Git 仓库

1. 在侧边栏打开 **Plugins → Add plugin**。
2. 选择 **Install a third-party plugin**，填入仓库地址：

   ```text
   https://github.com/crisvollerei/dsh-persona-shell
   ```

3. 安装后启用该 bundle；如果 DSH 提示重启，重启一次客户端。
4. 打开 **设置 → 人格套壳**，选择或编辑人格预设。

### 本地目录

```bash
git clone https://github.com/crisvollerei/dsh-persona-shell.git
```

在 **Add plugin** 中选择本地目录，指向克隆后的仓库根目录，再启用该 bundle。

## 会话开关与入口

安装启用后，助手完成一段汇报，聊天区就会显示人格版。运行中的助手输出保持官方原样；思考面板、图片、未知块和中断标记仍由官方组件处理，不另造一套正文渲染器。

**常用入口：**

| 界面上看到的 | 用来做什么 | 什么时候出现 |
| :--- | :--- | :--- |
| **人格** | 开关当前会话的套壳，不删除已有改写。 | 会话标题栏右侧。 |
| **会话设置** | 独立选择本会话的人格、范围，或安排手动接力。 | 会话标题栏，人格开关旁。 |
| **聊天室** | 用气泡短消息闲聊、讨论想法；不会自动提交到工作流。 | 工作会话顶部直接显示，点击打开。 |
| **`origin`** | 打开原文与人格版的独立对照窗口。 | 每轮最后一条已改写汇报。 |
| **调整表达** | 根据同一原文，仅重说这一次。长期偏好在插件设置管理。 | 每轮最后一条已结束的汇报；回落原文时也可打开查看是否能够重述。 |
| **可视化** | 打开原文阅读页，使用原文导览与可展开的重点阅读，保留原文顺序与代码高亮。 | 已保留完整原文的最终汇报；人格关闭时也可使用。 |
| **`※`** | 悬停预览原文，点击固定浮层。 | 定稿汇报的措辞变化达到阈值时。 |
| **`◈`** | 标识插件额外生成的静默状态播报。 | 手动开启功能、满足静默条件后。 |

插件总开关仍然优先：**总开关关闭，所有会话都不套壳。** 当前会话关闭后显示官方原文，重新打开可恢复已有改写。

报告阅读页是独立的只读展示，默认显示完整原文。主动分析后，可以用导览定位原句，或开启重点阅读、就地展开补充说明。原报告读起来太压缩时，可选择「顺畅阅读」，再主动生成逐段润色稿，讲清原文能确定的主体、动作和条件；每段都能核对原文。原文与重点阅读保持原有文字，已有顺畅稿、导览和外观切换不重复调用模型。详见[报告可视化](./report-visualization.md)。

阅读页的「阅读外观」可选择 Catppuccin、Nord、Rosé Pine 主题及明暗外观，默认跟随 DSH。正文不加常驻底纹，点击导览后在目标段落旁短暂显示定位细线。选择在本机保留，切换配色不调用模型。

### 当前会话与手动接力

点击顶部「会话设置」，可以选择「跟随全局默认」或指定角色，并分别选择全部汇报、仅最终汇报。点击保存后作用于后续汇报；未提交的选择关闭窗口后仍保留，页面刷新会丢弃本地草稿。

展开「交给另一位角色」，安排下一份汇报接力。会话设置中会显示等待状态；符合当前转述范围的下一份**原始汇报**到达后启用目标角色。等待期间可以取消；保存新的会话选择也会取消等待。已接手表示角色选择已经生效，不保证模型改写成功，失败时仍显示原文。

角色署名跟随每份汇报保存，切换不会改掉旧署名。新角色不会读取前一个角色的改写稿或私人偏好，也不会接管底层代理。完整边界见[会话人格与手动接力](./conversations.md)。

### 反馈给这份汇报

点击「调整表达」，可先选「短一点」「先说结论」「少些调侃」「更正式」，或写下希望怎么说，再点击「重新转述」。快捷项只填写要求，不自动调用模型；重述根据同一份原文，仅调整这一次。需要长期记住、更正或撤销偏好时，请到 **设置 → 人格套壳 → 记忆与约定**，不在对话中插入记忆管理或确认问题。会话偏好默认有效期为 24 小时；只有明确选择角色共享的会话偏好才随接力继续适用。

重新转述会进一步把原文中省略主语、堆叠名词的片段讲成完整句子，不猜执行者，也不以更短为由删掉事实、条件和风险。生成期间继续保留旧稿，通过校验后才替换；失败保留旧稿和输入。反馈绑定这份汇报的原角色，切换当前角色也不会记错对象。老版本未保存原文或署名的汇报不能重新转述。

## 角色消息区

点击工作页的「聊天室」，即可打开气泡浮窗闲聊或探讨想法。房间标题打开列表，可以新建多段独立讨论；标题下方的「成员」打开成员管理，「来源」管理工作参考。每个房间支持 1–8 位人格，头像采用能看清脸部的圆角图标组合，更多成员以数量补充。输入框上方可 @ 一至两位主讲，单人时隐藏这组选项。用户消息只显示一次，以小号 @ 标明主要对象；选中的人格依次协同回应，其余成员由一次轻量判断决定是否接话，最多两位，也可以都保持安静，不需要另开模式。原发言者和私人记忆的归属保持清楚；需要重试时从失败处重新生成后续接话，前面的完整内容保留。

Enter 发送、Shift+Enter 换行；输入框旁的斜向箭头展开或收起编辑区。打开、切换房间或选择人格不会主动生成消息。各房间的历史、草稿和参考分开，窗口不锁住工作页面。回复失败保留用户消息，可停止或重试；已发送请求在离开房间后可以继续完成，关闭后不轮询或弹出提示。

输入框上方可勾选「快捷回复参考」，按当前讨论和输入要求生成几条供用户选择的短句。需点击生成，点选仅填回输入框，由用户确认发送。当前不转交工作流。完整说明见[角色消息区](./role-chat.md)。

气泡旁的回复箭头可以引用某一句话，保留正在输入的文字；引用作者和当前 `@` 对象分开，不自动切换发言人格。可在发送前取消，发送后也能定位回原消息。要核对某次回复实际用了哪些工作来源、旧话题和偏好，打开 **设置 → 聊天室 → 房间参考**；这里也可暂停某段旧话题的自动引用。详见[房间参考信息](./role-chat.md#在设置页核对房间参考)。

同一设置面板内的 **房间讨论** 可以从原话整理候选方案、已确定或搁置的想法，附上用户依据并更正、撤销。状态只在本房间后续聊天中使用，不进入正式汇报或人格长期记忆。多人回复的临时职责随当轮点名与已完成发言分配，详情见[房间讨论状态](./role-chat.md#房间讨论状态)。

想把讨论转成工作要求时，点击聊天室的 **整理指令**，选择原话并生成可编辑草稿。也可用 **整理结论并填入**，按本次思考选择整理结论，安全填入后自动最小化；聊天室默认已开启思考时不重复询问。可以继续修改输入，实际发送仍由用户操作。详见[整理工作指令](./role-chat.md#整理工作指令)。

新房间第一次打开时参考当前工作会话，以当前汇报人格为初始成员；之后保存房间自己的来源与成员，切换工作页不会自动替换。可以在「来源」中手动接入当前或其他会话。只初始化正在进入的房间，焦点更新和相关提醒也限定在其来源中；未打开时不额外读取聊天和项目会话。详见[参考来源与工作焦点](./chat-context.md)。用户头像默认跟随 DSH 账号，未获取到时只显示消息气泡；「外观」可以自定义或完全隐藏头像，不会调用模型。

## 人格预设

| 内置预设 | 口吻与关系 |
| :--- | :--- |
| **大肥鱼（默认）** | 蓝发鲸鱼娘，自称「鲸鲸」，助手叫「小鲸鲸」。 |
| **大肥龙** | 管事大姐大风格的白龙娘，助手叫「小肥龙」。 |
| **Claude小姐** | 社区二创口吻，理性、克制、规矩感强。 |
| **小肥鱼（实验性）** | 转述助手「姐姐」的汇报，不把工作说成小肥鱼自己做的。 |
| **Gemini** | 同伴叫她「猫猫」。星星猫娘爱抢个开场，转述时会把原文已确认和仍待验证的事讲清楚。 |

不喜欢这些口吻，可以直接编辑人格卡，或粘贴一整段人设提示词生成新预设，不必改代码。内置预设不能删除；编辑时会自动另存一份，原版始终可以切回。

切换人格时，卡片保持原位，可通过勾选标记找到当前人格。点击卡片上的「头像」可上传和调整取景；修改内置头像会另存新人格。自定义人格可以更换或移除图片；未设置头像时，预设列表只显示文字，消息区显示字符头像。

编辑内容离开输入框后保存；保存期间继续输入的内容会保留。切换人格前会先保存当前草稿，失败时停留在原卡片，方便重试。从提示词生成的预设也只有保存成功后才收起预览；失败后可保留内容、修改名称再试。

插件刚启动、存储尚在恢复时，人格卡和预设操作可能暂时提示保存失败，等待恢复后重试即可。切换或编辑人格会清除受影响会话的临时语气样例，取消旧人格的在途转述；独立选择其他人格的会话保持原选择，历史汇报保留。

编辑器中的「发言关系」区分角色口吻重述与转达另一位助手。实验性小肥鱼默认以「姐姐」称呼主助手；子代理来源使用人格卡的子代理称呼。本次明确关系优先于卡片中的旧昵称和示例；不虚构角色之间的新对话。

正式汇报会用更顺口的语序和自然的长短句讲清原内容，保留原文的技术名称、数字、否定、条件和风险。口语化改变表达，不把未验证说成通过，也不把计划说成已执行；需要核对时仍可随时查看原文。

## 常用设置

日常调整都在 **设置 → 人格套壳**：

设置页分为「人格、转述、聊天室、记忆、外观、用量、高级」七个分区，一次只展示一类内容，初次使用选择一个人格即可。创建人格和调整当前人格按需展开；「聊天室」设置独立模型和思考开关；「记忆」集中管理偏好，「外观」设置自己的聊天头像，「高级」收纳转述模型、子代理开关和提示阈值。切换分区或收起编辑器时，未保存的草稿与生成预览仍保留。

| 想调整什么 | 去哪里改 |
| :--- | :--- |
| 换一个角色 | 启用其他预设，或粘贴人设提示词生成新预设。 |
| 让口吻更合适 | 编辑身份、汇报说话规则、通用语感、语气示例、禁区和称呼。 |
| 少改写一些内容 | 选择「仅最终汇报」；也可以在聊天顶部只为当前会话选择。关闭阶段性输出只跳过带工具调用的步骤。子代理过程与结论可分别控制。 |
| 让角色感知这段工作与会话节奏 | 在阶段性输出开关旁开启「允许过程转述参考运行信息」；只提供轻量元数据，补充最多一句。 |
| 调整改写变化提示 | 开关提示，或在高级项调整措辞阈值；不会重新生成改写。 |
| 长时间静默时听到播报 | 开启默认关闭的「静默状态播报」，设置等待分钟数；会增加模型调用。 |
| 查看或修改记忆 | 在记忆管理中添加、修改、置顶、删除条目，查看来源并指定适用范围；后台候选需采纳后使用。 |
| 换个模型来转述 | 指定改写所用模型；留空则跟随当前会话模型。思考模式默认优先关闭，不继承工作线程的推理档位。 |
| 恢复官方显示 | 关闭插件总开关，或关闭当前会话；会释放对应的渲染接管。 |

## 查看模型用量

打开 **设置 → 人格套壳 → 用量**，可以看今天、近 7 天或近 30 天的每日调用趋势，以及工作转述、聊天室和其他功能各用了多少 token。要对照聊天专用模型和转述模型，可以在「模型明细」按用途筛选，展开某个模型查看提供方、具体用途、调用次数与缓存等用量。

从安装支持统计的版本后开始记录，按本地自然日保留最近 30 天。只统计插件实际发出的请求；工作助手本身的用量不计入。多人聊天按实际发言、接话判断分别计数，显式重试或工具续接也可能让一条消息对应多次请求。没有用量回执时只计调用次数，不能据此推断免费。这里展示的是 token 消耗，实际金额以提供方账单为准。统计保存在本地，不记录消息正文、提示词或房间名。

## 原文对照

点击 `origin`，宽窗口下左边是原文、右边是人格版；窄窗口自动改用标签切换。**对照是浮层，不会把应用撑宽，也不搬动主正文。**

- 点击 `origin` 打开；点关闭、按 Escape 或点击遮罩退出。
- 窄窗口使用「原文 / 人格版」标签，支持左右方向键、Home / End；两侧各自保留阅读位置。
- 窗口展示点击当时的快照，需要读取更新后的文本时，关闭后重新打开。

对照不会再调用模型。完整的[渲染与快照规则](./architecture.md#原文对照的渲染与快照)见架构说明。

## 改写变化提示

默认不增加常驻对照。如果一条**定稿并通过校验**的人格汇报措辞变化达到阈值，或检测到数字、明确工作状态的局部否定变化，该条汇报末尾会出现小标记 `※`。阶段汇报也可以单独触发，不必等每轮最后一条；这个评估不增加模型调用。

- **悬停或键盘聚焦**：预览真实原文（由官方 Markdown 渲染，不是模型重新生成的摘要）；鼠标可以移入预览阅读。
- **点击或触屏轻点**：固定原文浮层，正文仍由官方 Markdown 组件整篇渲染。点「关闭」、按 Escape 或点浮层外可收起；键盘关闭后焦点回到标记。
- **浮层自动避让**：预览挂在页面浮层中，不受聊天区裁切；靠近消息底部时优先向上展开，空间不足时换边并限制高度，窗口变窄时限制宽度。滚动或调整窗口时跟随标记，标记滚出可见区域后收起；只有标记本身触发悬停，不占整行空白。
- **设置 → 改写变化提示**：可关闭全部提示；高级项可调措辞阈值，默认 **55/100**，越低越容易提示。滑块离开焦点后保存。数字和可定位的工作状态反转独立于措辞分数提示；单纯否定词数量变化仍受阈值控制。

> [!IMPORTANT]
> `※` 衡量的是**措辞变化，不是语义漂移概率**。没有标记，不等于内容安全或语义一致；重要结论仍应对照原文。

评分在本地计算，不增加模型调用。关于算法和误报、漏报，见[措辞变化评估](./architecture.md#措辞变化评估)。

## 过程运行信息

在 **设置 → 人格套壳 → 同时改写阶段性输出** 旁开启 **「允许过程转述参考运行信息」**，默认关闭。过程转述模型会获得一个无参数的只读函数 `get_tool_usage()`，可以自行决定是否查询，并按当前人设生成简短反应；没有固定台词模板。沿用 `processToolUsage` 配置键，一次查询同时返回阶段工具计数、可确认的工作性质，以及仅在内存中观察的会话节奏，不增加第二个查询或后台模型任务。

补充以正文下方的小字单独显示，**最多 40 个字符（含标点、空格）、单行、最多一句，每轮最多 3 条**。它不占正文的长度预算，不加入正文的措辞变化评分，也不调整原来的提示阈值；正文仍按原有字面量与长度规则校验。补充不合要求时只丢弃补充，正文照常处理。

可以参考的内容包括阶段内各类工具的调用与返回数、可确认的文件变更数，以及本会话轮次、本地小时和轮间空闲间隔；不提供工具参数或输出正文。未知信息保持未知。

这些信息只供当前人设参考，不强制改变正文长度或提醒休息，也不据此推断用户去做了什么。最终汇报不使用这条统计路径或它生成的语气样例。

统计以原始阶段汇报划分区间，不按模型查询次数累计。完整的[计数口径、函数限制与字段说明](./architecture.md#过程运行信息)见架构说明。

## 静默状态播报

在 **设置 → 人格套壳 → 静默状态播报** 开启，**默认关闭**。静默阈值默认 **5 分钟**，可设置 **1–60 的整数分钟**，离开输入框或按 Enter 后保存。

它会根据可观察的运行活动，额外用人格口吻说一两句，显示在输入区上方，并固定带上 `◈` 前缀。**无新观测不重复调用；它不是主模型消息，也不是完成度或剩余时间预测。**

**这是可选的“旁路状态生成”，不是对已有正文的严格改写。** 它不回写主会话、不成为后续转述样例，但仍会消耗提供方额度，也可能与主任务共享限流。提示词和本地规则不能保证语义完全忠实。

只为前台正在查看、仍在运行且未等待用户的主会话生成；每轮最多额外调用 3 次。主模型恢复正文、观测变化、切换人格或本轮结束时，会取消过时结果。

详细的[观测范围、调用上限与视图租约](./architecture.md#静默播报的观测与生命周期)见架构说明。

## 风格记忆

在设置页开启「记住偏好与约定」，明确的简短表达偏好会及时记录。也可手动添加记忆，指定当前人格、所有人格或当前会话；互动约定与共同经历保留在对应人格或会话中。

设置页按「使用中 / 待确认 / 历史」管理记忆。新建、更正和撤销先展示内容、原话依据与影响范围，确认后生效；更正固定原记录的归属，撤销不建立相反偏好。旧版语气纠正迁移为候选，确认采用后才使用；语言、句长等统计仅保留作诊断。「这次」「本次」等临时表达留在当前会话，默认一天后失效。

「后台整理记忆候选」默认关闭。开启后，会把有上限的用户短消息片段发送给当前转述模型，增加模型用量；约每 5 分钟或积累 8 条同会话、同人格消息整理一次，不阻塞正文转述。生成的候选需由你采纳，模型不会自行把推测变成生效记忆。

汇报转述、过程补充、单次重说与静默播报共用表达偏好规则，每次最多选取 5 条，总内容不超过 600 字符。共同经历与会话情况不增加到正文或静默播报中。

展开「最近使用情况」，可查看偏好是否实际提供给模型请求，以及其他条目为什么没有选中。三个计数和可展开的明细支持按人格、发言渠道筛选，默认收起，不打扰对话。「已提供」不代表模型一定遵守；被修改或删除的旧内容不会从使用记录恢复。完整规则见[记忆与接力基础](./memory.md#最近使用情况)。

关闭记忆会停止各渠道的采集与使用、新增使用记录和在途整理，保留已存内容；清空会同时移除条目、待确认项目、待整理片段、交接记录、使用记录与近期诊断样本。插件等待存储恢复后才采集，启动期间的清空同样有效；确认更正、撤销、删除和清空会取消过时的转述，清除受影响的临时语气样例。

## 显示与兼容

运行中的输出、思考面板、图片、未知块和中断标记由官方组件处理。遇到渲染契约不兼容或其他插件接管冲突时，插件保留官方显示，设置页会提示人格显示已暂停。

关闭再打开可在问题排除后重试。支持范围和当前限制见[使用边界](./architecture.md#使用边界)；部署与认证选项见[配置参考](./configuration.md)。
