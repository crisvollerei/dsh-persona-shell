# 报告阅读页

最终汇报旁的 **可视化** 打开独立阅读页。页面保留源工作流最终报告的完整原文、顺序与 Markdown 结构，提供原文导览、可展开的重点阅读和按需生成的顺畅阅读。正文保持统一墨色，不添加常驻句子底纹。人格改写稿、聊天室和私人记忆不参与分析，正式汇报与源工作流不会因此改变。

只打开页面会读取原文和已有分析缓存，立即可以阅读全文。首次点击 **分析阅读重点** 才调用模型；已有结果时直接使用。**重新分析** 明确发起一次新请求，失败仍保留原文与上次分析。关闭页面会停止本页尚未完成的请求；最小化保留阅读位置和已经主动发出的请求。

## 原文导览与重点阅读

默认显示 **完整原文**。导览只列出能够可靠定位的主要结果、风险与条件、待确认事项等入口，点击直接定位原文，不另写一份摘要。目标段落左侧短暂显示细侧线，风险与条件使用暖色，其余使用主题强调色；提示消失后保持原来的阅读位置。不存在的类别不占位置。

手动切换到 **重点阅读** 后，页面按原顺序折叠明确属于补充细节的段落。每处都有展开入口，可以就地查看，再收起；切回完整原文会恢复全文。定位、展开、收起和切换视图都在本地完成，不调用模型。

未分类内容、重要结论、风险、条件、待确认事项和相关上下文保留显示。本地条件与风险保护优先于模型的细节分类；列表、表格、代码和无法可靠映射的排版也保持显示。没有可折叠的内容时保留全文，不强行缩短。

本地保护按明确的条件、否定状态和适用范围识别，不因「不同」「未来」「需求」或「在本次更新中」等普通措辞单独锁住整段。模型没有明确标为次要细节的段落仍保持展开；分类与本地规则都不能代替人工核对。

较早的标注缓存如果没有段落分类，仍可阅读与定位，不会自动追加分析请求。用户可以主动重新分析以获取新的导览信息。

## 顺畅阅读

选择 **顺畅阅读** 会先读取该报告已有的润色缓存，没有结果时显示 **生成顺畅稿**。只有主动生成或重新生成才调用一次可视化模型。它按原段落顺序把省略主语、名词堆叠或过度压缩的说明整理成完整句子，降低每句话的信息密度；不是摘要，也不重新检查项目。

每次生成或重新生成前，会提醒润色可能遗漏信息或改变原意，**不保证信息准确**；重要结论、操作条件与风险仍需对照原文。确认后才调用模型，取消不会生成。可勾选 **今日不再提醒**，确认生成后在本机按本地日历日期保存，次日恢复提醒；查看缓存不弹出，也不将选择写入人格记忆。

主体只能来自原文已明确的执行者、对象或证据，未知时不猜。独立事实、数值、技术字面、否定状态、条件、风险、来源与待用户确认的事项都要求保留。步骤和列表保持顺序，代码、表格、引用等复杂块保留原样；不跨段搬移信息。每个改写段旁可展开对应原文，所有段落完整显示，不使用重点阅读的折叠规则。

完整 JSON 围栏、缺省协议版本、可识别的字段别名和返回顺序差异会在本地归一化；缺少或重复的段落使用对应原文，不因局部问题丢弃整份稿件。普通同义表达、词面条件数量和排版差异只提示核对，不按词频一律退回原文。技术字面损坏、新数值、可明确识别的状态翻转或不安全内容仍会保留该段原文。这些检查不能证明语义一致，读者仍可就地核对。无法解析的输出、生成中断、来源改变或保存失败时，保留原文与已有顺畅稿，不自动追加修复调用。

顺畅稿和原文分析分别缓存，互不覆盖。**复制** 始终复制完整原文；**复制顺畅稿** 明确复制润色后的文字。切换回完整原文可继续导览和重点阅读，不会把润色文本当成原文定位依据。关闭停止本页未完成请求，最小化保留主动发出的请求。

## 阅读外观

在阅读页的 **阅读外观** 中选择阅读主题。默认 **跟随 DSH**，也可选择 Catppuccin、Nord 或 Rosé Pine。跟随 DSH 时使用客户端当前外观；自选主题的明暗默认跟随客户端，也可固定为浅色或深色。主题与外观选择只保存在本机，换报告或重开阅读页后继续沿用，不写入人格记忆。

主标题与章节标题使用两级强调色，正文保持中性色和原有强调格式。条件与风险通过持续可见的导览入口和原文表达保留，不依靠临时侧线保证阅读，也不根据标题颜色推断验证状态。代码内部颜色和原生工具栏继续由宿主渲染器负责。主题切换立即生效，不重新分析，也不改变原文、折叠状态或模型用量。

导览定位、外观、放大和恢复均在本地完成，不重复调用模型。临时侧线不更改段落宽度或正文排版；减少动态效果时保留静态定位提示。关闭或最小化阅读页时清除临时提示。

主题配色参考 [Catppuccin 官方色板与使用指南](https://github.com/catppuccin/catppuccin/blob/main/docs/style-guide.md)、[Nord 官方配色规范](https://www.nordtheme.com/docs/colors-and-palettes/) 和 [Rosé Pine 官方色板](https://rosepinetheme.com/palette/)。阅读页根据实际文字尺寸与背景调整部分强调色对比度，属于阅读界面适配。

## 原文与标注边界

原文分析只选择原文依据、分类原文段落并指出相关上下文，不生成新的报告正文。依据位置由后台重新计算。找不到、存在歧义、落在代码或 Markdown 语法中的位置会局部略过，不替换文字，也不补造新结论。复制原文始终取得完整原始报告，包括重点阅读时暂时折叠的说明。顺畅阅读的逐段润色是独立展示，不改变这些依据。

全文采用宿主 Markdown 渲染器，代码保留原有语法高亮。定位提示只附在经过核对的原段落上；折叠只控制已经核对过的整段显示，并在原位置提供展开按钮，不改写或搬动正文。不能可靠映射的排版保持完整可读，不强行定位或折叠。

阅读页支持最小化、放大和关闭，可单独选择明暗外观，减少动态效果跟随客户端。关闭后焦点回到原报告入口。阅读页与聊天室轮流占据前台，另一页最小化保留；两者都最小化时，阅读页入口位于聊天室上方，只有一个入口时使用右下角空位。

## 模型和用量

在 **插件设置 → 高级 → 报告可视化** 可单独指定提供方、模型和思考开关。默认跟随转述模型。**顺畅阅读默认开启思考**，采用模型公布的默认强度，开关与重点分析独立；重点分析仍默认关闭思考。能力未知时由提供方决定，不宣称已确认开启。修改设置只影响之后明确发起的生成，不自动调用模型。

用量页单独列出 **报告可视化**，按实际调用模型记录调用和 token 回执，顺畅稿也计入此类。同一次主动分析同时提供原文定位依据与段落分类；生成顺畅稿是另一次明确的请求。查看缓存、使用导览、展开说明、切换已有阅读方式或调整外观不计为模型调用。

## 范围

当前提供只读阅读页，不执行模型生成的 HTML、脚本或操作，不加载模型指定的外部素材。原文自身不会被重新措辞；顺畅稿也保留数字、条件、路径和命令。模型对重要程度与表达的判断仍可能有遗漏，完整原文始终可读。

单次最多保留 18 处原文定位依据，合计不超过原文的 25% 且不超过 1200 字符。这些依据用于本地核对和导览，不给原文铺设底纹。局部不适用的位置直接略过，非法结构则拒绝并显示简明原因；本地校验不额外调用模型，失败不回显模型原始输出。

缺少完整原文、报告尚未结束或超过独立长度上限时会明确提示，不静默截断。分析缓存按原始报告及协议区分；人格重新措辞不改变原报告，也不会自动再次调用分析模型。

阅读页被动保留接收到的完整最终报告文字快照，不采集用户偏好，也不发起模型调用。单份原文上限为 24000 字符、256 段；每个工作会话最多保留最近 16 份，并受原文与结果合计 192000 字符的缓存预算限制。较早快照可能被清理，原工作会话的正式汇报不受影响。未安装本功能时产生的报告，仅在插件已有可信最终原文缓存时可读取，不根据页面上的人格化文字补造原文。
